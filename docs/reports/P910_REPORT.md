# P910 — training client hooks, chat, quit and team UI

Based on `45789f61`, the working tree contains the P910 implementation and evidence; no commit or push was made. Only the 29 assigned training matrix rows changed. **24 rows are certified implemented, 3 keep explicit gaps, and 2 were ruled n/a in Claude's review (TRN-0197, TRN-0228).**

The client now receives local training death/station events on the game thread, preserves complete local station-launcher identity, and suppresses duplicate wire echoes. Chat reception and private local echo feed a single recipient latch, consumed once; training private messages use the commander cue. The composer uses these shared receive/echo hooks; GroupNoEcho remains silent locally, matching the native echo guard. Local friendly NPC commands use the native training policy. The server's existing queued-order timer exempts training ships. Critical tips replace slot zero, coast/cloak approve their toggle state, Team take-me-to honors command permission, and donation eligibility stops updating during lessons. Ordinary multiplayer has no local-training delegates and retains its existing timer, chat, targeting, donation and toggle behavior.

A shared exit owner restores HUD style and keymap/filter, clears lesson overlays/remote view/death camera, resumes the clock and disposes the embedded host. It is reached by completion, explicit quit, join timeout, connection abort, transport loss/mission departure, a new normal connection, and window unload. In-flight menu Quit, hangar Exit and the quit key now ask “Quit the Current Training Mission?”; cancel retains the lesson, confirm skips its postlude. Prelude/postlude quit uses the same confirmation. Confirmation keystrokes are consumed so held Escape cannot advance a cancelled slide and held Enter cannot immediately launch the chooser selection. Back-to-hangar and no-team screen transitions remain suppressed while training owns the view.

The recommendation advances when the recommended lesson is launched, skips Mission7, caps at Nanite, and clears the startup suggestion before Introduction or a prelude opens. Native `-training` and the `--training` alias start Free Flight. Timer-driven slideshow changes now start the next clip and use real elapsed seconds, rather than a fixed 60-frame assumption. Both HUD styles use the shared behavior; no native 2-D coordinate/layer convention was changed.

## Native intent

**Design:** training owns player input, command access, messages and screen transitions so demonstrations can teach one action at a time. Its lifetime must also own temporary UI state and release it on every termination route. The port implements those rules in the shared client model for both visual styles; the native hardware-HUD substitution is treated as permitted visual variation, while the player's selected style is restored.

**Era constraint:** native offline training shares the client IGC universe and can synchronously buy equipment, issue drone orders and hold raw model pointers. This port embeds a server behind loopback. Local simulation events therefore cross a game-thread queue; complete station-launcher identity is retained before retirement because the network message has only a ship launcher field. The unresolved immediate-purchase rule and the separate enemy-eye pair are explicit architecture gaps, not visual differences.

**Bugs and modern approach:** the native timeout-loop comment alone is misleading; training's exception is in the command timer's arming site (`WinTrek.cpp:10720-10721`), so the port gates the actual server-owned timer. Native death-wait initialization and null-launcher safety rulings already documented in P882a are retained; this lane does not reopen them or claim those bug fixes as new native rules. A modern implementation would use one scoped training session with typed local transactions, event records and disposable preference ownership, rather than global flags plus callbacks. This change centralizes the lifetime cleanup within the existing architecture; it does not disguise the remaining transaction/visibility gaps or resurrect removed Mission7.
