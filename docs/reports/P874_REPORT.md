**Date:** 2026-10-28 · **Author:** Hermes (Pi lane) · **Task:** P874 brief

## Goal & method

The existing parity matrices (`parity-matrix.csv`, `sim-rules-matrix.csv`) cite the
native `Igc`/`FedSrv`/`WinTrek`/`clintlib` bodies heavily but leave several native
areas uninventoried, so the scorecard cannot see their gaps. P874 inventories six
of those areas as new matrices with the same 17-column sim-rule shape, each searched
honestly against the port first (grep `src/`, `tools/`, existing reports/CSVs) before
anything is marked missing.

Classification follows the native-intent rules: behaviour parity, visuals may differ;
`n/a` only for what physically cannot exist in the port (DirectPlay/Win32/COM/AGC/
compile-time plumbing) or memory/ownership with an equivalence argument; modding/dev
tools that matter are inventoried as `tools/` commands. Native rules cite
`~/Development/Allegiance/src/<file>:<line>`. Every row carries a `reachability`
(production / config-only / test-only) as required for the sim-rule shape.

### Notes per area
- **lobby:** The native MSN/Zone Federated-Messaging lobby (game-info UDP broadcast,
  mission cookies, roll-call, club tables) maps onto the modern HTTP `ServerRegistry` +
  `LobbyHeartbeat`. Listing, filters (P806), rank (Career), squads, find-player (P761b)
  are implemented; several legacy behaviours (paused/empty-game hiding, IP allowlist,
  version gate, chat-log relay) are not carried over.
- **soundengine:** The port's P614 voice-budget/priority/limit-group system closely
  mirrors native `ds3dengine` ranking (DSVirtualSoundBuffer dynamic priority). Gaps are
  genuinely 3D: full rolloff for positioned world sounds, doppler, and a generic ASR
  primitive. Hardware DirectSound scaling is `n/a` (era).
- **allsrvui:** The Windows admin dialogs themselves are `n/a`; capabilities are rows.
  Boot, admin cheats (relocate/timescale, secret+bearer gated), game-settings config,
  start/stop and mission/core selection are implemented. Notable gaps: persistent ban
  list (neither native UI nor port has one), a privileged sysop-only broadcast channel,
  and a first-class admin player-list/console surface (roster is internal + opt-in lobby
  publication).
- **effect:** `src/effect` is predominantly the legacy effect-editor/viewer toolkit, so
  most rows are per-family visual summaries marked `n/a` ("visuals may differ
  (Domingo)"), with the port's renderers cited as evidence. The 5 gameplay-timing rows
  (debris lifetime, build/pulse timing, hull-hit feedback, tiered explosion audio, shared
  effect clock) are all implemented — 100%.
- **bots:** Native Pigs (JScript bot behaviours: scout/bulldozer/chatter/Creator) and
  Wopr (C# director + strategies) map onto the extensive MCP bot suite. 9/10 eligible
  implemented; only scripted social chat is missing/limited, and stress-test harness
  scripts are `n/a` (era). Showcase finale rows remain in `p819-bot-policy.csv`
  (cross-referenced, not duplicated).
- **model-tools:** Native `mdlc` (compile/optimize/convert/compressanim/genheader/info)
  and `mdledit` map onto `tools/mdl-to-glb` (export to glTF, round-trip import,
  `.cvh` collision, texture decode, verify). Animation compression is the one true
  missing command; interactive-editor is partial (external glTF editors substitute);
  `genheader` is `n/a` (compile-time plumbing).

  doppler (SND-0006), and a generic ASR loop primitive (SND-0008). Audio/Gameplay lane;
  no image needed, but gameplay-affecting — pair with a Live-tier test. ~4 rows.

- **P880 — model tooling.** Native-format animation compression (TOOL-0004) and an
  explicit optimize pass (TOOL-0002). Tools lane. ~2 rows.
- *(Optional, larger)* **Interactive model editor** (TOOL-0009) — a real editor is a
  significant effort; external glTF editor + import round-trip is the interim. Would need
  an image-capable/UI lane.
